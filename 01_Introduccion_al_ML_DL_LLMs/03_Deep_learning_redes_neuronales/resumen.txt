Cada imagen numero es una matriz y esta formado por pixel
Cada pixel tiene un valor entre 0 (Blanco) y 255 (Negro) y entre medias toda la escala de grisees
Si fuera a color. Tendriamos una matriz de 3 dimensiones (RGB)
Al comprimir una imagen se pasa de 0-255 a 0-1

Para la escala de grises (2 dimensiones) pasamos a 1 dimension poniendo todos los PXs seguidos.
Por lo que la matriz fianl esta formada por:
    * Cada fila es el numero expresado en pixels
    * Cada columna es valor (0-1) del pixel x
    * Cada columna va a ser una neurona. 
Una vez hecho el APLANAMIENTO (RE-SHAPE) se mete en la Red Neuronal (formula del sumatorio).
    Una imagen (28px, 28px) -> Pasa a 784 Neuronas (28x28). Necesitas tantas tantas neuronas (784) como pixels tiene la imagen (28x28)

Si en vez de solo 0 e 1 tienes 0 - 9. Necesitas la C (La convolucion) y la NN (rede neuronal sencillita)
        - C -> Convolucion es pasar de algo que entiende el humano (imagen) a algo simplificado hasta su minima expresion y así entiende la máquina 
            Se pasa de una matriz (224,224,4) a traves de calculos para reducir el tamaño de la imagen pero lo hace más profundo (13x13x128 - )
        - A la 13x13x128 Se hace el APLANAMIENTO y se mete a la red neuronal

hiperparametro -> Lav valvulas de fuera de la caja negra. Que modificas antes de entrenar

Batch: numero de muestras para entrenarlas. Se usa para que sea mas rapido se puede paralelizar con las GPUs


Gradiente -> es el "error " que disminuye al entrenar el modelo
Epoch -> Pasada completa de todo el conjunto de datos para el entrenamiento. El numero de pasadas del data set para entrenar. El batch (numero) es el mismo y mezclas los datos

Learning rate. Ratio de aprendizaje (es un hiperparametro)
