# database

CSV creados por nosotros (`data/`) y capa semántica (`src/database/semantic_layer.py`): vistas DuckDB con comentarios, esquema generado y guía, como en clase. Generador con semilla fija (`uv run python -m database.seed`, fase 2b) que escribe el conjunto grande en `data_generated/`, sin Faker. Son datos: no sabe nada de LLMs (sección 3).
