# Recursos extra: Model Context Protocol (MCP)

Estos tres recursos permiten ampliar el tema desde perspectivas complementarias: comprender el protocolo, enriquecer las capacidades de un agente y validar servidores MCP durante el desarrollo.

1. **[Documentación oficial de MCP](https://modelcontextprotocol.io/docs/getting-started/intro)**  
   Punto de partida para consultar los conceptos, la arquitectura y la especificación del protocolo. Es la referencia más fiable para profundizar en clientes, servidores, herramientas y recursos MCP.

2. **[Skills.sh - directorio de skills para agentes](https://www.skills.sh/)**  
   Catálogo de capacidades reutilizables que se pueden incorporar a agentes de IA. Sirve para entender cómo una *skill* puede aportar instrucciones y procedimientos especializados sin necesidad de crear un servidor MCP para cada caso.

3. **[MCP Inspector](https://modelcontextprotocol.io/docs/tools/inspector)**  
   Herramienta oficial para probar y depurar servidores MCP. Permite inspeccionar las herramientas, recursos y prompts expuestos por un servidor, por lo que resulta especialmente útil durante la implementación y las prácticas.
