Validación de datos en Python con Pydantic

Pydantic es una librería de validación de datos que permite definir modelos de datos en Python y validar datos de entrada contra esos modelos. 
Pydantic proporciona una API de validación de datos flexible y fácil de usar, que se puede integrar con otras librerías y frameworks de Python.
